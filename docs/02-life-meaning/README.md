# 生命与意义

> 追问二"生命存在的意义是和熵增对抗吗？"与追问三的入口。

薛定谔说生命"以负熵（negentropy）为食"。这句话很迷人，但**"生命在对抗熵增"是比喻还是机制？**对抗熵增是生命的*手段*还是*意义*？手段和意义混为一谈，是这一类讨论里最常见的滑坡。

这个分类的五本书，从物理学交界处（薛定谔）走到复杂性科学（米歇尔），再经过演化的冷眼（道金斯）与文明叙事（赫拉利），最后落回每个具体的人：当你知道自己会死（亚隆），"活着"这个问题就不再抽象。
