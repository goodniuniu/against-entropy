> 追问一"热寂是所有生命的终点吗？宇宙本身呢？"的主战场。

热力学第二定律（second law of thermodynamics）说：孤立系统的熵（entropy）不减。这句话被十九世纪的人放大成"宇宙终将热寂（heat death）"的预言，一百多年来反复被恐慌、被引用、被误用。

这个分类的五本书，任务是把你从"热寂恐慌"带到一个更诚实的宇宙图景：哪些是**物理学事实**（第二定律成立、时间箭头存在），哪些是**学术假说**（热寂作为宇宙终局依赖具体宇宙学模型），哪些其实是**修辞**（"熵的世界观"式的文化论断）。
