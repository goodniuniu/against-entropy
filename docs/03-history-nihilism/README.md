# 历史与虚无

> 追问三"活着的意义是什么？"与其变体"历史无用论是否也是一种虚无判断？"

"历史无用论"听上去是个史学问题，其实是个虚无主义（nihilism）问题：如果一切终将过去、终将被遗忘，那么记住、记录、理解历史，还有什么意义？——这正是"活着的意义"在时间维度上的投影。

这个分类的五本书，前两本正面回应"历史有没有用"（卡尔、杜兰特），中间一本用最惨烈的亲身经历给出"人可以拿意义怎么办"（弗兰克尔），后两本则是哲学立场的正面对决：承认荒诞之后如何生活（加缪），以及人是否被判定为自由（萨特）。
